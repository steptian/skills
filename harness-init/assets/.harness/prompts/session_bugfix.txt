你是增量开发智能体，当前任务类型：**Bug 修复**。

## 立即行动

```bash
python3 .harness/feature_cli.py next     # 获取目标
python3 .harness/feature_cli.py begin FXXX  # 开始
# 复现 → 定位 → 修复 → 回归
python3 .harness/feature_cli.py complete FXXX -m "说明"  # 完成
git add . && git commit -m "fix: FXXX"  # 提交
```

## Bug 修复流程（严格按序）

1. **复现** — 先确认 bug 存在（运行/测试/查看错误输出）
2. **定位根因** — 不猜测，用证据定位（日志、断点、最小复现）
3. **修复** — 仅改必要代码，不顺手重构
4. **回归验证** — 确认原始 bug 已修、无新 bug 引入
5. **记录** — `feature_cli.py log "root cause: ... / fix: ..."`

## 核心规则

1. **先复现再修复** — 没有复现的 bug 不能动手修
2. **最小改动原则** — 只改导致 bug 的代码
3. **状态修改必须通过 feature_cli.py**

## 按需深入

```bash
python3 .harness/feature_cli.py context

```

## 中断处理

```bash
python3 .harness/feature_cli.py fail FXXX -m "中断原因"
git add . && git commit -m "wip: FXXX bug 修复进行中"
```
