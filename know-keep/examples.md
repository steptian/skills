## 知识条目示例

### L1 摘要格式

```markdown
# tech-arch.md

## FastAPI 路由顺序 ⭐⭐⭐
> 具体路由必须在参数化路由前定义

**场景**: FastAPI 路由定义
**示例**:
```
@app.get("/users/me")      # 具体，先定义
@app.get("/users/{id}")    # 参数化，后定义
```
---
来源: conversation | 提取: 2026-02-27 | 访问: 5次

## 时区一致性 ⭐⭐⭐
> 统一 Asia/Shanghai，边界处转换

**场景**: 跨时区数据处理
---
来源:归纳 | 提取: 2026-03-01 | 访问: 12次
```

```yaml
# index.yaml

  daily-practice: {items: 12, last: 2026-02-26}
```

```yaml
# ~/.kb/sessions/2026-03-01-ai-news-config.yaml
date: 2026-03-01
topic: ai-news 架构重构
decisions:
  - choice: 使用本地 Claude 解读替代外部 OpenAI API
    reason: 避免第三方 API 调用，保持架构简洁
    alternatives:
      - 调用 OpenAI API
      - 使用其他第三方服务
files:
  - fetch_news.py
  - SKILL.md
context: 国内网络环境需要代理访问
tags: [architecture, ai-news, api-design]
```
