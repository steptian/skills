# know-keep 参考文档

## 模式详解

### 1. 对话提取模式 (--chat)

**适用场景**: 日常对话后快速提取学到的知识点

**流程**:
1. 分析当前会话所有消息
2. 识别可复用的知识模式
3. 抽象提炼 → 写入知识库

**优势**: 无需扫描文件，快速直接

### 2. 项目扫描模式 (默认)

**适用场景**: 整理项目文档中的知识

**目录规模检测**:
```bash
# 快速检测（不递归）
find . -maxdepth 1 -type f | wc -l    # 当前层文件数
find . -maxdepth 1 -type d | wc -l    # 当前层目录数
```

**规则**:
- 文件 < 50 且 目录 < 20 → 直接扫描
- 文件 >= 50 或 目录 >= 20 → 警告并询问
- 用户目录 (~) → 提示使用 --chat

**扫描文件**:
- CLAUDE.md
- progress.md
- docs/ 下的 md 文件
- README.md

### 3. 知识同步模式 (--sync)

**目标**: 将高频知识沉淀到 `~/.claude/CLAUDE.md`

**筛选标准**:
1. 高频使用 - 每次对话都可能用到
2. 通用原则 - 不依赖特定项目
3. 用户偏好 - 工作流、编码规范

**执行流程**:
1. 读取 `~/.kb/` 所有知识文件
2. 读取 `~/.claude/CLAUDE.md` 当前内容
3. 分析每条知识，标记推荐级别
4. 输出分析表格，逐条确认
5. 用户确认后写入

**推荐级别**:
| 标记 | 含义 | 条件 |
|------|------|------|
| ✅ 推荐 | 合并 | 符合全部筛选标准 |
| ⚠️ 可选 | 询问 | 部分符合，看使用频率 |
| ❌ 不适合 | 跳过 | 项目特定/低频 |

### 4. 压缩模式 (--compress)

**触发条件**: 知识库条目超过 50 条时建议使用

**操作**:
1. 合并相似条目
2. 降级详情 L2 → L1
3. 清理过期知识（90天未访问且重要性 ⭐）

## 配置说明

### 首次运行

1. 检查 `~/.kb/config.yaml` 是否存在
2. 不存在 → 询问用户选择存储位置
3. 写入配置，后续严格遵守

### 路径选项

| 选项 | 路径 | 特点 |
|------|------|------|
| user | ~/.kb | 跨项目共享（推荐） |
| project | ./.kb | 跟随当前项目 |

> 一旦配置确定，后续运行必须严格遵守，不得随意更改

## Token 估算

| 操作 | 估算 Token |
|------|------------|
| --chat 提取 | 500-2000 |
| 项目扫描 | 2000-10000 |
| --sync 审查 | 1000-3000 |
| --compress | 500-1500 |

**计算方法**:
- 中文: chars / 4
- 英文: chars / 6
- 总计 = 输入 + 输出
