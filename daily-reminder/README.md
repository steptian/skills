# daily-reminder

日程计划 Skill，支持每天定时提醒待办事项。

## 功能特性

- ✅ 待办事项管理（添加/删除/修改）
- ✅ 优先级设置（高/中/低）
- ✅ 定时提醒（固定时间 + 截止前提醒）
- ✅ 多渠道通知（系统通知 + 语音播报 + 终端）
- ✅ 自然语言交互

## 使用方式

```bash
/daily-reminder              # 查看今日待办
/daily-reminder --add "任务"  # 添加待办
/daily-reminder --done 3     # 标记完成
/daily-reminder --config     # 配置提醒
```
