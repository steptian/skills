# 定价计算示例输出

## 示例 1：正向定价（成本 → 售价）

**用户输入**：`定价 成本13.5 毛利率15%`

**输出**：

```markdown
# 📊 直播电商定价分析报告

## 📋 基础参数

| 参数 | 值 |
|------|-----|
| 进货成本 | ¥13.50 |
| 目标净毛利率 | 15% |
| 直播间提成 | 36% |
| 发货运费+打包 | ¥4.00/单 |
| 退货率 | 20% |
| 退货运费险 | ¥4.00/单 |

## 💰 定价建议

**推荐售价：¥39.80**

基于 20% 退货率的行业常态场景计算，扣除所有直接成本后可实现约 15% 的净销售毛利率。

## 📊 场景对比

| 场景 | 建议售价 | 净毛利率 | 说明 |
|------|---------|---------|------|
| 无退货 | ¥35.72 | 15% | 100% 确认收货，最优情况 |
| **20% 退货（常态）** | **¥39.80** | **15%** | **推荐参考** |
| 叠加平台费 2% | ¥41.49 | 15% | 含技术服务费 |
| 退货不可二次销售 | ¥46.68 | 15% | 食品/美妆等特殊品类 |

## ⚠️ 风险提示

1. **不要按裸毛利定价**：仅考虑进货成本的 15.88 元售价会导致严重亏损
2. **退货率波动风险**：如果退货率升至 25%，需相应提高售价
3. **提成谈判空间**：若能将提成降至 30%，售价可降至约 ¥36.50
4. **品类差异**：食品、美妆等退货不可二次销售的品类需按 ¥46.68 定价

## 📐 验算（20% 退货场景）

按 100 单发货计算：
- 有效营收：39.80 × 80 = ¥3,184
- 进货成本：13.50 × 80 = ¥1,080
- 发货运费：4 × 100 = ¥400
- 退货运费：4 × 20 = ¥80
- 直播间提成：3,184 × 36% = ¥1,146.24
- **总成本**：¥2,706.24
- **净毛利**：3,184 - 2,706.24 = ¥477.76
- **净毛利率**：477.76 ÷ 3,184 × 100% ≈ **15%** ✓
```

## 示例 3：自定义参数定价

**用户输入**：`成本20 提成30% 退货15% 帮我算卖多少钱能赚20%`

**输出**：

```markdown
# 📊 直播电商定价分析报告

## 📋 基础参数

| 参数 | 值 |
|------|-----|
| 进货成本 | ¥20.00 |
| 目标净毛利率 | 20% |
| 直播间提成 | 30% |
| 发货运费+打包 | ¥4.00/单 |
| 退货率 | 15% |
| 退货运费险 | ¥4.00/单 |

## 💰 定价建议

**推荐售价：¥46.31**

基于 15% 退货率场景计算，扣除所有直接成本后可实现约 20% 的净销售毛利率。

## 📊 场景对比

| 场景 | 建议售价 | 净毛利率 | 说明 |
|------|---------|---------|------|
| 无退货 | ¥40.00 | 20% | 最优情况 |
| **15% 退货** | **¥46.31** | **20%** | **推荐参考** |
| 叠加平台费 2% | ¥48.78 | 20% | 含技术服务费 |

## 📐 验算（15% 退货场景）

按 100 单发货计算：
- 有效订单：85 单
- 有效营收：46.31 × 85 = ¥3,936.35
- 进货成本：20 × 85 = ¥1,700
- 发货运费：4 × 100 = ¥400
- 退货运费：4 × 15 = ¥60
- 直播间提成：3,936.35 × 30% = ¥1,180.91
- **总成本**：¥3,340.91
- **净毛利**：3,936.35 - 3,340.91 = ¥595.44
- **净毛利率**：595.44 ÷ 3,936.35 × 100% ≈ **15.1%**

> ⚠️ 验算结果显示实际毛利率约 15.1%，建议售价调整为 **¥54.55** 以确保 20% 目标。

**修正计算**：
```
售价 = (20×85 + 4×100 + 4×15) ÷ (85 × (1 - 0.30 - 0.20))
     = (1700 + 400 + 60) ÷ (85 × 0.50)
     = 2160 ÷ 42.5
     = ¥50.82
```

**最终建议售价：¥50.82**
```
