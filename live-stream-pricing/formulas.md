# 直播电商定价公式推导

## 一、基础毛利率概念

### 1. 销售毛利率（标准口径，财务报表通用）

```
销售毛利率 = (售价 - 进货成本) ÷ 售价 × 100%
```

**正向计算售价**（已知目标毛利率）：
```
售价 = 进货成本 ÷ (1 - 目标销售毛利率)
```

**示例**：进货成本 13.5 元，目标毛利率 15%
```
售价 = 13.5 ÷ (1 - 15%) = 13.5 ÷ 0.85 ≈ 15.88 元
```

### 2. 成本毛利率（俗称加价率）

```
成本毛利率 = (售价 - 进货成本) ÷ 进货成本 × 100%
```

**正向计算售价**：
```
售价 = 进货成本 × (1 + 成本毛利率)
```

**注意**：成本毛利率 15% 对应的销售毛利率仅约 13%，容易混淆！

## 二、直播电商净销售毛利率公式

直播电商需要扣除多项成本后的**净销售毛利率**才是实际到手利润。

### 核心成本项

| 成本项 | 计算基数 | 说明 |
|--------|---------|------|
| 进货成本 | 确认收货订单数 | 退货可二次销售时仅计有效订单 |
| 发货运费+打包 | 发货订单数 | 每单必发生 |
| 退货运费险 | 退货订单数 | 退货时产生 |
| 直播间提成 | 确认收货金额 | 按销售额比例计提 |
| 平台技术服务费 | 确认收货金额 | 可选，主流平台约 2% |

### 场景公式

#### 场景 A：无退货（100% 确认收货）

设售价为 X，目标净毛利率为 R：

```
(X - 进货成本 - 发货运费 - X×提成率) ÷ X = R

化简：
X = (进货成本 + 发货运费) ÷ (1 - 提成率 - R)
```

**示例**：成本 13.5，运费 4，提成 36%，目标 15%
```
X = (13.5 + 4) ÷ (1 - 0.36 - 0.15) = 17.5 ÷ 0.53 ≈ 35.72 元
```

#### 场景 B：有退货率（按 100 单发货基准）

设售价为 X，退货率为 T（小数），目标净毛利率为 R：

**有效订单** = 100 × (1 - T) = 100 - 100T

**有效营收** = X × (100 - 100T)

**总成本**：
- 进货成本 = 进货单价 × (100 - 100T)（退货可二次销售）
- 发货运费 = 运费 × 100
- 退货运费 = 退货运费险 × 100T
- 提成 = X × (100 - 100T) × 提成率

**净毛利公式**：
```
(有效营收 - 总成本) ÷ 有效营收 = R

代入：
(X × (100-100T) - 进货×(100-100T) - 运费×100 - 退货运费×100T - X×(100-100T)×提成率) ÷ (X × (100-100T)) = R
```

**化简求 X**：
```
X × (100-100T) × (1 - 提成率 - R) = 进货×(100-100T) + 运费×100 + 退货运费×100T

X = (进货×(100-100T) + 运费×100 + 退货运费×100T) ÷ ((100-100T) × (1 - 提成率 - R))
```

**示例**：成本 13.5，运费 4，退货率 20%，退货运费险 4，提成 36%，目标 15%
```
有效订单 = 100 × 0.8 = 80
分子 = 13.5×80 + 4×100 + 4×20 = 1080 + 400 + 80 = 1560
分母 = 80 × (1 - 0.36 - 0.15) = 80 × 0.49 = 39.2
X = 1560 ÷ 39.2 ≈ 39.80 元
```

#### 场景 C：退货不可二次销售

某些品类（食品、贴身衣物、美妆）退货后无法再卖，进货成本全额损耗：

**总成本**：
- 进货成本 = 进货单价 × 100（全部计入损耗）
- 发货运费 = 运费 × 100
- 退货运费 = 退货运费险 × 100T
- 提成 = X × (100 - 100T) × 提成率

**公式**：
```
X = (进货×100 + 运费×100 + 退货运费×100T) ÷ ((100-100T) × (1 - 提成率 - R))
```

**示例**：成本 13.5，运费 4，退货率 20%，退货运费险 4，提成 36%，目标 15%
```
分子 = 13.5×100 + 4×100 + 4×20 = 1350 + 400 + 80 = 1830
分母 = 80 × 0.49 = 39.2
X = 1830 ÷ 39.2 ≈ 46.68 元
```

#### 场景 D：叠加平台技术服务费

在场景 B 基础上增加平台技术服务费（按确认收货金额计提）：

```
X = (进货×(100-100T) + 运费×100 + 退货运费×100T) ÷ ((100-100T) × (1 - 提成率 - 平台费率 - R))
```

**示例**：成本 13.5，运费 4，退货率 20%，退货运费险 4，提成 36%，平台费 2%，目标 15%
```
分子 = 13.5×80 + 4×100 + 4×20 = 1560
分母 = 80 × (1 - 0.36 - 0.02 - 0.15) = 80 × 0.47 = 37.6
X = 1560 ÷ 37.6 ≈ 41.49 元
```

## 三、反向验算公式

给定售价 X，反推净销售毛利率：

```
净毛利率 = (有效营收 - 总成本) ÷ 有效营收 × 100%
```

**示例验算**：售价 39.80，成本 13.5，运费 4，退货率 20%，退货运费险 4，提成 36%

```
有效营收 = 39.80 × 80 = 3184 元
总成本：
  - 进货成本 = 13.5 × 80 = 1080 元
  - 发货运费 = 4 × 100 = 400 元
  - 退货运费 = 4 × 20 = 80 元
  - 提成 = 3184 × 36% = 1146.24 元
  - 总计 = 1080 + 400 + 80 + 1146.24 = 2706.24 元

净毛利 = 3184 - 2706.24 = 477.76 元
净毛利率 = 477.76 ÷ 3184 × 100% ≈ 15.01% ✓
```

## 四、快速计算口诀

**简化公式**（退货率 T，提成率 P，目标净毛利率 R）：

```
售价 = (进货成本 × (1-T) + 运费 + 退货运费 × T/(1-T)) ÷ (1 - P - R)
```

这个公式按单件有效订单计算，结果与 100 单基准一致。
